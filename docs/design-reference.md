## Motion and interaction contract

- Logo reveal: approximately 1.25 s, once per browser session; Skip close control; no form or source-processing block. Reduced-motion users skip the reveal.
- Hero: approximately 20 s geometry cycle, finite low-amplitude camera tilt, coral/cyan crossed threads, translucent shell. WebGL1 signed-distance rendering; CSS static illustration on unsupported/context-lost devices. Visible Pause control; no idle rendering while offscreen or tab-hidden. The sculpture is explanatory, not a live agent or processing indicator.
- Landing: gentle one-time section rise/fade, capsule float, soft object drift, scroll-driven art parallax and small hover lift. Footer pauses decorative motion globally. Actions and text remain stable.
- Graph: 320 ms focus/overview camera transition, manual drag/pan, zoom, previous-node navigation, close detail and fit overview. Reduced motion uses direct camera changes. Camera interpolation updates only the SVG viewBox instead of rerendering every table each animation frame.
- Node groups are layout categories, not invented dependencies. Counts reflect all records; canvas displays up to six records per group. Group pagination/full searchable tables expose every saved node. Cross-links come from dependencyGraph, with semantic relationships dashed.
- Landing workspace/case/external navigation uses a clear destination/consent dialog. Source originals retain existing permission confirmation and server enforcement. Ordinary node selection is read-only; a presentation dialog never grants authentication or changes server access.
- Modal close X, Cancel/Close, Escape and focus controls are retained. No capability is activated by an animation or a navigation acknowledgement.
