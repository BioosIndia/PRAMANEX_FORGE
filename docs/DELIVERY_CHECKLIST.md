Reference recreation pass 3, 4 October 2026. Continues the existing published FORGE source. Source/PDF meanings, original maturity labels and the MD development rulebook are preserved. The rulebook is development guidance, not an end-user feature.

BUILT = an implemented bounded artifact, with direct item-level proof or external qualification still needed. SPECIFIED = defined requirement not delivered as an operational enterprise capability.
