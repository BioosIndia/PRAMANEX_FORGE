# Data rights and handling

Fixtures are synthetic and labelled. User-supplied data must have an explicit recorded permission and match the declared CMC task purpose. Do not upload confidential company, patient or employee records without organization authorization and approved security/privacy controls.

Original bytes are stored under workspace-scoped server-created keys. Reads require an authenticated active workspace membership. Extraction keeps original values and source lineage. No browser-local preference storage is used as durable professional evidence.

AI-provider transmission requires an explicit user confirmation. Only bounded approved facts are sent for drafting; document extraction sends the permitted original. The provider API uses store=false. This option alone is not a full data-processing, retention or residency contract.

Retention is an organization-review target (365 days initially), not an automatic deletion policy. No destructive deletion is enabled in this release. Organizations must define retention, legal holds, recovery, identity assurance and operating procedures before real regulated use.
