# Scope and explicit limits

The original source documents and 178 exact target items are retained. The current scope is an authenticated, bounded engineering release, not completion of every expanded enterprise requirement.

- Canonical F01–F14 and F-P01–F-P05 have executable bounded workflows and source-linked engineering tests.
- A1–A18 are typed logical specialists. Current default execution is deterministic, not eighteen active language models.
- X01–X68 have an explicit registry and bounded projections/held contracts. See FEATURE_MATRIX.md for implementation versus specification. A capability projection does not prove the full enterprise capability.
- Internal workspace membership authorizes the workspace. External partner grants separately authorize only an exact object revision, with redacted dependencies, expiry, revocation, shared notes and explicit original-file permission. Site audience remains independently controlled.
- JSON/CSV/text and typed XML/DOCX/XLSX original-byte source extraction are available. Unicode PDF/DOCX/HTML and technical handoff ZIP use actual frozen server records. Live vision inference and AI authoring need server secrets and pinned model identifiers, plus actual provider tests.
- Live LIMS/MES/QMS/RIM/publishing integrations require vendor-specific contracts, credentials, permissions and executed end-to-end evidence. No Veeva or LORENZ integration is claimed.
- Source-backed local ontology, explicit supplied-market rule classification, observed stability statistics and gap-based question candidates are implemented as bounded reviewed records. Comprehensive global regulatory coverage, agency-qualified eCTD preflight, physical twin validation, stability extrapolation and trained/calibrated query-risk prediction are not established.
- Workspaces use an optimistic-concurrency aggregate with versioned history: 4 MB aggregate limit, 20 workspaces per owner, 500 parameters per source, 5 MB original files, 60 write operations/user/minute. This is not an unbounded enterprise-scale architecture.
- Continuous drift scheduling, off-site production backup/restore, regional residency, performance SLOs and operational incident coverage are not established by local tests.
- S-P01–S-P06 individual definitions are absent from the audited documents and remain unresolved.
- No professional-user pilot, organization-specific validation or production regulatory qualification has occurred.
