# FORGE account, command-center and motion release — 4 October 2026

This additive release retains FORGE's own Bio Lab / Selectra / QGen reference allocation, source-defined CMC meaning, saved evidence, eighteen deterministic specialist roles, nine-part implementation map, human authority and controlled exports. It does not clone BEACON's identity or turn the target blueprint into a claimed completed enterprise product.

## Delivered

- FORGE-owned email/password creation, sign-in, session inspection and sign-out. Readable Password fields with show/hide and visible caret; private unverified manual accounts; rate limits, same-origin writes, session rotation/revocation and bounded account payloads.
- Landing account navigation and workspace account/sign-out routes. Existing trusted platform records remain accessible. Explicit one-to-one dual-session linking preserves the existing actor and evidence; nonempty new identities cannot silently migrate. DB guards block late writes under a retired ID.
- Configuration-gated Google OAuth adapter (state, nonce, PKCE, issuer/audience/expiry/verified-email checks and RSA signature verification). This does not provision real Google credentials. Shared membership and object grants reject unverified manual identities, including at the SQL boundary.
- Atomic owner workspace quota with no orphan membership on quota failure. Revocation remains possible if a former member loses verification.
- Six current-snapshot command-center stages and a truthful next-step recommendation. Existing batch/status/graph/decision panels remain intact. Counts come from saved records; stale checks never become a current success score.
- Useful landing-space additions: compact evidence control strip, connected workspace illustration (clearly labelled with no fake metrics), six-step interactive delivery spine and tighter balanced section spacing.
- Higher-resolution adaptive WebGL sculpture (up to 1024 px longest dimension, bounded pixel budget), slow membrane/capsule deformation and brighter dimensional material response. SVG source/network/shield illustrations use differentiated float/squeeze/orbit motion; precise technical labels and click targets stay stable.
- Animated fallback shown before WebGL is ready and on unsupported/context-loss devices. Decorative motion pauses when offscreen/tab-hidden, with user Pause and reduced-motion support. No animation implies live processing or saved workflow success.
