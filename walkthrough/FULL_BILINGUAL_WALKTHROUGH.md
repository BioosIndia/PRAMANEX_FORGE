## What it is

Hinglish: FORGE source documents se supported CMC facts, missing information aur draft ko responsible review ke saath jodta hai.

English: FORGE organizes source-backed CMC facts, visible gaps and controlled draft candidates for human review.

## Why I made it

Hinglish: CMC mein ek number ka method, unit, batch aur source bhi important hai. Sundar draft agar missing fact ko guess kare to useful nahi. Maine original record se draft tak relation aur conflict visible rakhne ke liye FORGE banaya.

English: A CMC value needs its source, unit, batch, method and version. A fluent draft is not useful if it invents missing science. FORGE is my independent work sample for making those dependencies and gaps inspectable.

## How the work proceeds

Hinglish: Permitted original save hota hai. Exact values aur unka context nikala jata hai. Conflict/missing requirement dikhte hain. Supported reviewed facts relevant Module 3 location se judte hain. Quality checks aur independent human review ke baad bounded packet ban sakta hai.

English: The workflow stores the permitted original, extracts values with their context, identifies gaps and conflicts, maps scoped content to Module 3, and checks draft candidates before independent human review and controlled output.

## What the user should receive

Hinglish: User ko cited CMC gap assessment, supported values, missing studies/results, draft candidate, review state aur clear next action milta hai. Drug X proof synthetic hai. 98.6% aur 99.1% assay conflict unresolved hai; dissolution guess nahi kiya gaya.

English: The output is a cited CMC assessment, supported facts, visible missing evidence, draft candidate, review state and next action. The Drug X proof is synthetic; its 98.6% versus 99.1% assay conflict remains unresolved and no dissolution result is invented.

- Open /working-proof. This is the saved, read-only synthetic recruiter case. It is different from /demo, which is the separate session-only sandbox.
